== Description ==

Solstice is a block theme for HVAC and home service businesses. The palette swings from deep navy and
ember orange in bold full-width sections to soft off-whites where there is reading to do, and modern serif
headlines pair with a rounded sans-serif for body and interface text. The pattern library covers what a
trade site actually needs — a services grid, a coverage area map, a credentials strip, reviews with star
ratings, before-and-after comparisons, an FAQ accordion, opening hours, and an estimate request form —
with templates for the blog, archives, and search.
