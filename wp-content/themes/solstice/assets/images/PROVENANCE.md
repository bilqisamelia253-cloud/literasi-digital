# Image provenance

The photographs in this directory were generated with AI in Magnific AI (see
the image credits in `readme.txt`). The icons and the service area map were
drawn by hand for this theme.

## Machine-readable marking (EU AI Act §50(2) alignment)

The files listed as AI-generated below carry the IPTC digital source type
marker (`XMP-iptcExt:DigitalSourceType = trainedAlgorithmicMedia`), applied
2026-10-23 after `solstice-img-3.webp` was resized to 2000px, and to
`solstice-img-4.webp` on 2026-10-26.

`screenshot.png` shows none of these photos, so it carries no marker.

To tag a newly added AI-generated image:

    exiftool -overwrite_original \
      "-XMP-iptcExt:DigitalSourceType=http://cv.iptc.org/newscodes/digitalsourcetype/trainedAlgorithmicMedia" \
      <file.webp>

…and add it to the list below.
